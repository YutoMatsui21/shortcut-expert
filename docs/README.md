# ドキュメント案内

現行の製品要件・受入条件は[確定要件](ui-redesign-requirements.md)を優先します。過去資料は現行仕様の根拠には使いません。

## 基本資料
- [確定要件](ui-redesign-requirements.md)：何を実現し、どの条件で受け入れるか
- [設計・アーキテクチャ](design.md)：モジュール構成、責務分担、実装方針
- [開発・検証ガイド](development.md)：起動・ビルド・試験
- [開発ツール](development-tools.md)：開発環境、取得・監視の手順
- [コードレビュー](code-review.md)：レビューの観点と判断

## 詳細資料
- [操作別の設計](operations/)：ウィンドウ切替、配置、閉じる、画面移動など
- [機能別の設計](features/)：一覧・記録・設定・通知・画面制御
- [保存](storage/)：SQLite、移行、削除、受入条件
- [調査・実測](research/)：技術的な判断根拠、probeの結果
- [検証手順](validation/)：結合検証・画面の受入
- [過去資料](archive/)：過去の要件・設計・振り返り

各詳細フォルダのファイル名は、扱う機能や調査対象に対応しています。検証済みの範囲は各文書の記述日時・対象buildと合わせて確認してください。
