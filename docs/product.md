# プロダクトの目的・思想

本書は、Shortcut Expertが**なぜ存在し、何を大切にして開発するか**を定める。機能の範囲・具体的な振る舞い・初回公開の合格条件は[製品要件・受入条件](ui-requirements.md)が正本。技術的な実現方法は[設計・アーキテクチャ](design.md)、現在の進捗はIssue・PRを参照する。

## 解決したい課題

Windowsの日常操作には便利なショートカットキーがあるが、存在を知らない、覚えていても思い出せない、操作のたびに調べるのが面倒、といった理由でマウスを使い続けやすい。学習のために日常作業を中断したくないという課題がある。

本プロダクトは、主にWindowsで普段からPCを使い、ショートカットを身につけたい人を対象とする。

## 目指す価値

**普段どおりPCを操作している間に、対応するショートカットを知り、少しずつ使えるようになること。**

- マウス操作をきっかけに、対応するショートカットをその場で知る。
- 別の学習時間や強制的な練習を必要とせず、日常の操作の中で試せる。
- マウス・キー操作の実績を振り返り、自分の操作習慣の変化を把握できる。

ショートカットの習得そのものが最終目的ではない。**日々のPC操作をより速く、快適にすること**を目指す。ただし、キー率の改善だけで実際の時間短縮や習得効果が証明されたとは扱わない。

## 判断の基本原則

1. **作業を邪魔せずに学べること**：強制的な再入力や専用の練習時間を前提にしない。通知や学習状態は利用者が制御できるようにする。
2. **案内の正確さを優先すること**：マウス操作とキー操作の同等性が確かでなければ、誤ったショートカットを案内しない。検出できる操作数を増やすことより、正しく案内できることを重視する。
3. **利用者の入力内容を守ること**：学習に必要な操作の集計と、文字・キー生ログなどの取得／保存を区別する。具体的な保存禁止事項は[製品要件](ui-requirements.md)を優先する。
4. **実際の利用価値で判断すること**：機能数やテスト件数だけで成功を判断せず、日常環境で機能するか、役立つかを重視する。

## 対象範囲と成功の考え方

- 初回公開では、Windows 11の日常的なウィンドウ操作に対象を絞る。対象の8操作、除外条件、公開合格条件は[製品要件](ui-requirements.md)が正本。
- **最も重要な成果は「操作効率の改善」**。日常のPC操作に必要な時間や手間が減り、より快適に操作できることを成功の中心に置く。
- ショートカット使用率（キー率）の向上や継続利用は、操作効率の改善につながり得る**補助指標**として扱う。これらの数値だけで時間短縮・快適さの改善が実証されたとは判断しない。
- **操作効率をどう測定するか、達成閾値をいくつにするかは未決定**。実測できていない効果を断定せず、プロダクトの成果指標と初回リリースの受入条件を区別する。
