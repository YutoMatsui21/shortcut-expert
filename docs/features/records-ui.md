# 記録画面・集計と比較

**責務**：対象操作の7／30日記録、前期間比較、フィルタ・ソートと欠測の説明を、確定したデータから一貫して表示する。表示要件は[製品要件](../ui-requirements.md)、見た目は[Figmaの記録画面](https://www.figma.com/design/mMfK6fQQzfhUqRHR7jsGne?node-id=275-6552)を正本とする。

## 1. データの流れと責務

`Rendererの表示条件 → Preloadの限定IPC → Mainの入力検証 → DurableCoach／Repository → CoreのrecordsReadModel → Renderer`

- `src/shared/records.ts`が期間・フィルタ・ソートの型を定義。MainはmainFrame、許可した値だけを受理し、任意SQLや全履歴取得を公開しない。
- Mainが利用者のローカル日付と確定settingsを取得し、Coreの直列キューで現在／前期間を**同じrevision**のデータから構築する。Repositoryの取得は7日表示で14日、30日表示で60日に限定する。
- `AppShell`が期間・フィルタ・ソートを非永続の画面状態として所有。画面往復では維持し、再読込／再起動では初期値へ戻す。日付・設定・revision・queryの変化で更新し、古い非同期応答は表示しない。
- 操作の表示順・名前は[学習一覧](learning-ui.md)と同じ8操作registryを共有し、旧IDを混ぜない。

## 2. 期間・集計・欠測

| 項目 | 設計上の約束 |
| --- | --- |
| 期間 | 今日を含むローカル暦日7／30日と、直前の同日数。日途中の時間補正なし |
| 全体キー率 | 操作率の平均ではなく、全キー回数 ÷（全キー＋全マウス回数） |
| 未観測 | 値は`null`／`—`。観測済みの0回・0.0%と区別 |
| 前期間比較 | 同じ対象操作集合で比較。既知の回数差を算出し、率差は両期間の分母が正の場合のみ`pt`表示 |
| 欠測警告 | 欠測を0で埋めず、取得済み値を表示して別途`hasMissingCoverage`を返す |

- `CoreのrecordsReadModel`が合計・差分・ソートを担当。BigIntで安全に計算し、丸め前の値で順位を決め、表示値は小数1桁に丸める。安全整数超過は保全エラーとする。
- 片方の期間に比較できる根拠がまったくなければ差分は`—`。既知0件は回数差を算出できるが、分母0の率差は算出しない。legacy countsも根拠のある値だけを扱う。
- 欠測判定は**選択された操作の両期間**を対象に、未観測・coverage gap・部分日を確認する。日長を固定24時間とせずローカル日付境界を使う。対象操作集合が空なら警告しない。

## 3. フィルタ・並び替え・表示

- **期間**：7日／30日。
- **フィルタ**：学習中・習得済み（初期値）／学習中のみ／すべて。現在の学習状態を**現在・前期間の両方**に適用し、保存済み件数は変更しない。
- **ソート**：キー率が低い順（初期値）／マウス操作が多い順／改善が大きい順／キー操作が多い順／操作回数が多い順。未定義値は末尾、同値はregistryの順序を保持する。
- 欠測infoはKPIと各操作行を区別する。hover／focus／クリック（Enter・Space）で表示し、Esc・外側クリックで閉じる。画面端で欠けず、対象条件変更時には古いinfoを破棄する。[欠測時のFigma例](https://www.figma.com/design/mMfK6fQQzfhUqRHR7jsGne?node-id=367-3715)。
- 800pxではKPI縦積み・操作2段、920px以上ではKPI横並びの表へ切り替える。数値・欠測のサンプル表示を実記録と混同しない。

## 4. 検証と限界

- **unit**：`tests/records.test.ts`（日付・丸め・比較・既知0）、`tests/records-query.test.ts`（本番SQLite Worker・revision・フィルタ／5ソート・欠損・並行更新）、Main/Preloadの不正query拒否。
- **結合**：隔離smokeの`--comparison`等で、Main→Preload→ReactのKPI・行・info、画面往復と再読込、800／920／1120／1360pxを確認する。
- **証拠の限界**：人工fixtureの成功は自然入力の認識精度、実DPI・文字拡大、実スクリーンリーダー、OS通知・NSISの受入を証明しない。
