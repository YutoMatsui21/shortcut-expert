# 検出アーキテクチャの調査・リファクタリング設計

**目的**：将来ウィンドウ操作やテキスト操作を追加するとき、既存の検出処理への変更をできるだけ少なく、分かりやすくする。そのために現状を事実ベースで把握し、後続の設計・移行仕様・Issueを段階的に確定する。

- **調査対象**：`native-helper/` のイベント観測・候補生成・送信と `src/main/observer.ts` から `src/core/detector.ts` までの受信・採用経路。
- **コードの基準**：`main` commit [29bd044be4dc7d71e38179d556d6a272787fe949](https://github.com/YutoMatsui21/shortcut-expert/tree/29bd044be4dc7d71e38179d556d6a272787fe949)（2026-11-06調査）。後続の変更はこの調査結果を更新せず、別の設計・実装資料として区別する。
- **位置付け**：これらは「Step 1：現状調査」のスナップショットであり、正本の仕様やリファクタ後の決定事項ではない。製品仕様は [製品要件](../../ui-requirements.md)、現行設計の正本は [設計](../../design.md)、操作別の条件は [操作別設計](../../operations/README.md) を参照する。
