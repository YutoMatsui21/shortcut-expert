- **操作の成立**：マウスは「背後に見えている別の通常ウィンドウを直接クリックし、クリック先が前面になる」、キーは「Alt+Tabで選択を確定し、最終的に別の通常ウィンドウへ切り替わる」。両入力とも切替前と切替後の対象HWNDおよび入力由来を照合する。入力/foregroundイベント単独を結果の確証としない。

## 5. 集計・記録・保存（U03〜U06）

- キー率 = **キー操作回数 /（キー操作回数 + マウス操作回数）**。分母0は「記録なし」（0%ではない）。分母が正でキー回数0なら **0.0%** と区別する。括弧内はキー回数／総操作回数。
- 一覧のキー率は**直近7日間**。記録画面は**直近7日間／直近30日間**の切替。基準は**利用者のローカル日付、今日を含む暦日**。
- 前期間の比較は同じ日数の**直前の連続期間**。例：2026-10-17の7日表示→10/11〜17、比較→10/4〜10。30日表示→9/18〜10/17、比較→8/19〜9/17。
- **当日途中でも時間補正しない**。現在得られている記録をそのまま集計する。表示中に新しい操作が記録されたらデータに応じて再計算する。
- 全体キー率・キー/マウス回数・キー率の前期間差（**pt**）・各操作の率と内訳・率バー等は正式Figmaの表現に従う。表示桁や厳密な丸め方式はSpecで明文化する。
- **記録は自動削除せず、無期限に保持**。7/30日表示は維持し、将来の「全期間」分析ができるよう日別・操作別集計を保全する。ユーザーによる**全記録の手動削除**機能は維持する。旧バージョンで既に削除された日付は復元できない。
- **利用開始前・観測していない期間と、観測中に操作が0件だった日を区別**する。現行の回数レコードにこの区別はないため、必要な計測範囲の情報を追加する。記録のある日だけを集計し、存在しない日を根拠なく0件として埋めない。
- **J01（確定）：比較する現在・前期間に観測できなかった時間帯があっても、取得済みの回数で比較結果を算出する。** 欠測を0回として補完したり、日数・時間数で補正したりしない。いずれかの期間に欠測がある場合は、比較結果の近くにinfoアイコンを表示し「一部の時間帯で記録を取得できていないため、実際の利用状況と異なる可能性があります。」と説明する。比較できる観測・記録根拠が前期間に**まったくない**場合は、存在しない記録を0回と仮定せず、比較結果は「—」。一方、計測が成立した期間に操作が実際に0回だった場合は既知の0回として扱い、回数差を計算する。キー率の分母が0の場合、率の増減は「—」。現在期間も欠測がある場合、同じ警告を表示する。
- **並び替え5種類**：キー率が低い順／マウス操作が多い順／改善が大きい順／キー操作が多い順／操作回数が多い順。同値なら一覧での操作順を維持。率・改善値が計算できない操作はその並び替えの末尾。欠測を0%として先頭に出さない。
- 初回の記録なし・選択期間に記録なし・前期間比較不可など、Figmaの空状態を区別する。比較可能性の具体的な日付・観測範囲判定は技術設計で明記する。

- 通知ID・Windowsアプリ識別・インストール状態でのアクティベーション・OS側で抑制された場合の扱いは技術設計で検証する。音やクリック動作を勝手に変更しない。
