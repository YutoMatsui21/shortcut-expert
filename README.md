## 主な機能

### マウス操作からショートカットを学ぶ

ウィンドウの最大化や切り替えなど、普段のマウス操作に対応するショートカットキーを通知します。

作業を中断して調べる必要はありません。

### 自分のペースで学習する

ショートカットごとに「学習中」「習得済み」「対象外」を設定できます。

覚えたショートカットの通知を止めて、まだ覚えていない操作に集中できます。

### 操作習慣の変化を振り返る

ショートカットの使用率（キー率）や操作回数を記録します。

直近7日間と前の7日間を比較して、操作習慣の変化を確認できます。

## インストール

**対応環境：Windows 11（64bit）**

1. [GitHub Releases](https://github.com/YutoMatsui21/shortcut-expert/releases)から最新版のインストーラーをダウンロードします。
2. インストーラーを実行します。
3. インストール完了後、Shortcut Expertが自動起動します（起動しない場合はスタートメニューから開いてください）。

   設定の「Windowsへのサインイン時に起動」をONにすると、次回サインインから画面を開かずトレイへ常駐します（初期OFF）。計測の停止／再開状態は、アプリを再起動しても保持されます。

## 使い方

1. **いつもどおりPCを操作する**  
   マウス操作に対応するショートカットが通知されます。
2. **ショートカットを使ってみる**  
   次からは通知されたキーで操作してみましょう。
3. **学習状況を振り返る**  
   ショートカットの使用状況を確認し、学習状態を管理できます。

アプリを閉じてもシステムトレイに常駐し、操作を記録します。記録は設定から一時停止できます。

## 対応する操作

Windowsのウィンドウ操作を中心に、以下の操作に対応しています。

| カテゴリ | 操作 |
|---|---|
| アプリ・ウィンドウ | タスクバーからアプリを開く、ウィンドウを切り替える |
| ウィンドウ操作 | 最大化、最大化解除・最小化、閉じる |
| ウィンドウ配置 | 左右半分、四隅への配置 |
| ディスプレイ | 別のディスプレイへ移動する |

※ 管理者権限で動作するアプリや特殊なウィンドウ、リモート環境などでは、一部の操作を正しく認識できない場合があります。

## プライバシー

Shortcut Expertは、操作の記録をすべてPC内で管理します。

- **ローカル保存**：操作回数、使用率、学習状態などをPC内に保存します。
- **入力内容は保存しない**：入力した文字、キー入力の生ログ、閲覧URL、ウィンドウタイトル、画面画像などは保存しません。
- **外部送信なし**：操作履歴を外部サーバーに送信せず、アカウント登録も不要です。

操作記録はアプリの設定から削除できます。
