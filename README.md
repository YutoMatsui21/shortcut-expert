# Shortcut Expert

**いつものPC操作から、ショートカットを身につけよう。**

Shortcut Expertは、Windowsのショートカットキーを自然に習得するためのデスクトップアプリです。

マウスで操作すると、対応するショートカットキーを通知。さらに、ショートカットの使用率を記録して、習得状況を振り返れます。

> **開発中**：現在、初回リリースに向けて開発・検証を進めています。一般向けのダウンロードはまだ提供していません。

## 主な機能

### 1. マウス操作からショートカットを学ぶ

ウィンドウの最大化や切り替えなど、普段のマウス操作に対応するショートカットキーをWindowsの通知でお知らせします。

作業を中断してショートカットを調べる必要はありません。

※ 通知は、対応するショートカットを確実に判定できる操作に限ります。

### 2. 覚えたいショートカットを管理する

操作ごとに学習状態を設定できます。

- **学習中**：ショートカットの通知を受け取る
- **習得済み**：覚えた操作の通知を停止する
- **対象外**：学習しない操作の通知を停止する

習得済み・対象外に設定しても、操作の記録は継続します。

### 3. ショートカットの使用状況を振り返る

ショートカットをどれくらい使えているかを、直近7日間の「キー率」で確認できます。

**キー率 = ショートカット操作回数 ÷ 全操作回数 × 100**

記録画面では、操作回数や前の期間との変化も確認できます。

## 対応する操作

初回リリースでは、Windowsのウィンドウ操作を中心に、以下の8操作に対応する予定です。

| カテゴリ | 操作 |
|---|---|
| アプリ・ウィンドウ | タスクバーのアプリを開く |
| | ウィンドウを切り替える |
| ウィンドウの操作 | 最大化する |
| | 最大化解除・最小化 |
| | 閉じる |
| 配置 | 左右半分に配置する |
| | 四隅に配置する |
| 画面間の移動 | 別画面に移動する |

**対応状況：開発・検証中**

現在、一部操作の検出処理は実装されていますが、8操作すべての実際の入力による動作検証は完了していません。上記は初回リリースの対応予定範囲であり、すべてが現在利用できることを意味しません。

Win+Z・Win+Tabと、Snap Layout／Task Viewで選択する経路は初回対象外です。関連学習候補にも含めません。最大化は画面上端への直接ドラッグも対象です。Alt保持中の複数Tab、Win保持中の四隅への方向キー列、同じ窓への連続Win+↓は、それぞれ一連の操作を1件として扱う方針です。 同じドラッグで別画面へ移動し、最大化または四隅配置も確定した場合は、異なる2操作をそれぞれ記録し、案内可能なキーを1通知にまとめる予定です（未実装）。未実装の検出条件は[確定要件](docs/ui-requirements.md)・操作別Issueで追跡します。

上下半分への配置（`Win + Alt + ↑ / ↓`）は、一般的な横長画面で同等の標準マウス操作が確認できていないため、初回リリースから除外し、将来の候補として保留しています。

また、アプリ独自のショートカットや文字編集操作などは、初回リリースの対象外です。

## 使い方

1. **アプリを起動する**：Shortcut Expertを起動すると、対応するWindows操作の記録を開始します。
2. **普段どおりPCを操作する**：学習中の操作をマウスで行うと、認識できた場合にショートカットキーが通知されます。
3. **ショートカットを使ってみる**：対応するキー操作も記録されます。
4. **学習状況を確認する**：「ショートカット一覧」で学習状態を変更し、「記録」でキー率や操作回数を確認します。

画面を閉じてもアプリはトレイに常駐し、記録を継続します。記録は設定から一時停止できます。

## プライバシー

Shortcut ExpertはWindowsの操作を検出しますが、**入力した内容や操作履歴を外部へ送信しません。**

| 項目 | 扱い |
|---|---|
| 操作回数・キー率 | PC内に保存 |
| 学習状態・設定 | PC内に保存 |
| 入力した文字・キー入力の生ログ | 保存しない |
| 閲覧URL・ウィンドウタイトル | 保存しない |
| クリップボード・画面画像 | 保存しない |
| 外部サーバーへのデータ送信 | しない |
| アカウント登録 | 不要 |

操作記録はアプリの設定から削除できます。記録を全削除しても、学習状態などの設定は保持されます。

## 動作上の制限

- 一般的なWindows 11のウィンドウ操作を対象としています。
- 管理者権限で動作するアプリや独自のウィンドウ操作、リモート環境などは正しく認識できない場合があります。
- 操作の判定に十分な情報がない場合は、誤った通知を避けるため記録・通知を行いません。
- 現時点では自動起動に対応していません。
